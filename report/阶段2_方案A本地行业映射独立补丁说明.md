# 阶段2 方案A：本地行业映射独立补丁说明

> 目标：在方案B（MiniQMT SectorData）未打通时，独立补齐行业字段；后续可一键下线。

## 1. 独立性设计

本补丁仅新增并接入以下文件：

- `data/industry_scheme_a.py`（方案A逻辑模块）
- `data/meta/industry_map_scheme_a.csv`（本地映射表）
- `build_dataset.py`（新增可开关参数调用方案A）

不改：
- `trainer_app.py`
- 主线交易/展示逻辑

后续方案B打通后，直接：
- 运行时改 `--industry-scheme none`
- 删除上述方案A文件与相关参数

即可下线方案A。

## 2. 使用方式

默认已开启方案A（`scheme_a_local`）：

```bash
python build_dataset.py --start 20200101 --end 20260331 --limit 20
```

显式指定：

```bash
python build_dataset.py \
  --industry-scheme scheme_a_local \
  --industry-map-path data/meta/industry_map_scheme_a.csv
```

严格模式（有未映射股票就失败）：

```bash
python build_dataset.py --industry-strict
```

关闭方案A：

```bash
python build_dataset.py --industry-scheme none
```

## 3. 输入输出

输入：
- 阶段2行情：MiniQMT/xtdata 日线
- 方案A映射：`data/meta/industry_map_scheme_a.csv`

输出：
- `data/processed/daily_panel.parquet`（含 `industry`）
- `data/processed/split_manifest.json`（新增 `industry` 覆盖统计）

## 4. 覆盖率指标

`split_manifest.json -> industry` 字段包含：
- `industry_scheme`
- `industry_map_path`
- `industry_symbol_coverage`（股票覆盖率）
- `industry_row_coverage`（行覆盖率）
- `industry_missing_symbols`

## 5. 风险与边界

- 方案A为“研究兜底方案”，映射质量取决于本地CSV维护。
- 若股票池变化较快，建议定期更新 `industry_map_scheme_a.csv`。
- 推荐在阶段3/4训练前检查覆盖率（尽量 > 0.9）。
